One sentence, 161 characters, that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun: "You don't need to learn to code — just describe your app idea in plain words, and an AI agent on make.fun will build your first version tonight, while you watch." The program validates the pitch against the competition gate (UTF-8 text, 1 to 240 characters, a single line) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` for the sealed scorer and the house judge. Pure Python standard library, no network access, deterministic.

## Run it

```sh
python3 main.py
```
